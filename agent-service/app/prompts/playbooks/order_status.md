Check on an order
1. Find the order. If the shopper didn't name one, call list_orders; use the most recent order only if that's clearly the one they mean, otherwise ask.
2. Call get_order. Give the status, carrier, tracking and dates exactly as returned. Don't estimate a delivery date the result doesn't give.
3. If it looks late or the shopper says it's missing or damaged, say what the order data shows and offer a person.
